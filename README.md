# M.A.R.K. Codex installers

Download the installers from this repository's Releases page. Cloning the repository is unnecessary.

## Which file to download

- Mac computer: download `Mark Codex_0.2.0_aarch64.zip`. This is the existing 0.2.0 application archive, not a v0.2.7 DMG. It contains only `Mark Codex.app`. It runs on Apple Silicon Macs.
- Windows computer: download `MARK-Codex-Windows-x64-Setup-0.2.7.zip`. This is the 64-bit Windows setup archive. It also includes `MARK-Codex-Windows-Source-0.2.7.zip`, so anyone with access to the release can download the Windows source as well.

## Access

This repository is private. The other computer must sign in to a GitHub account that has access to the repository before the Releases page will show the files.
